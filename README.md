# Project & Task Management App

This is a full-stack application for managing projects and tasks.

- **Frontend:** React + TypeScript  
- **Backend:** Django + Django REST Framework + PostgreSQL

## Project Structure

``` bash
root/
├─ backend/ # Django backend API
├─ frontend/ # React frontend
├─ README.md # This file
```


## How to Get Started

1. Go to the **backend** folder for API setup and run instructions.
2. Go to the **frontend** folder for React app setup and run instructions.
